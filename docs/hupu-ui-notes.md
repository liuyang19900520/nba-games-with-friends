# 虎扑 NBA App 界面参考(Yang 2026-10-28 22:29-22:32 手机截图,文字整理)
原图在 pm leader 的附件库(box 的 Shell 读不到),以下是结构说明。

## 1. NBA 首页 > 球员榜 (顶部 Tab: 赛程 / 球队榜 / 球员榜 / 全球 / 选秀 / 日榜 / 新闻…)
- 筛选条: 赛季下拉「2026-27常规赛」, 切换「基础」/「进阶」
- 左侧竖向分类栏: 得分、篮板、前场篮板、后场篮板、助攻、抢断、盖帽、投篮命中率、三分总命中数、场均三分命中、三分命中率 ……
- 右侧每个榜单一块: 标题(得分榜), 列头「球队」「数据」; 前 5 名一行一个: 名次、头像、球员名、副行「36.0分 6.8板 8.3助」、球队名、数据值(大号);底部「查看全部 >」
- 示例: 得分榜 东契奇 36.0 / 爱德华兹 33.3 / 杰罗姆 29.8 / 马克西 28.8 / 阿德托昆博 28.5; 篮板榜 萨博尼斯 16.5 ...

## 2. 球队页 (红色主题色头部)
- 头部: 队徽、中文队名「底特律活塞」、英文名 Pistons、主场「小凯撒球馆」; 按钮「设为主队」
- 数据条: 东部第1 排名 | 总胜/负 3/1 | 主胜/负 1/0 | 客胜/负 2/1
- 社区入口/话题标签(可不做)
- Tab: 资讯 / 赛程 / 球员 / 数据 / 薪资 / 资料
- 球员 Tab: 「制服组」(总经理、主教练 头像+名), 球员表: 球员(头像、名、号码·位置) | 出场/首发 | 时间 | 得分 | 篮板 ... 按得分降序

## 3. 球员页 (队伍主色头部, 洛杉矶湖人紫金)
- 头部: 大头像、中文名「卢卡-东契奇」、英文名、所属球队 chip; 位置/号码「锋卫摇摆人 / 77号」| 年龄 27岁 | 身高 203cm | 体重 104Kg
- Tab: 数据 / 投篮 / 生涯 / 比赛 / 资讯 / 资料
- 数据 Tab: 子切换 季前赛/常规赛/季后赛; 「基础数据」网格(4列): 上场时间 35.5、得分 36.0、篮板 6.8、前板 0.3、后板 6.5、助攻 8.3、失误 5.8、抢断 1.3、盖帽 0.5、投篮命中率 48.4%、三分总命中数 21、场均三分命中 5.3、三分命中率 39.6%、罚球命中率 87.5%、利用失误得分、内线得分; 每个数值下方一个红色小标签「联盟第N」(联盟排名)
- 比赛 Tab: 赛季下拉(2026-2027) + 常规赛/季前赛/季后赛; 「赛季数据」比赛日志表: 日期 | 主客 | 胜负 | 首发 | 上场时间 | ... (可横向滚动)

## 对 MVP 的启示
- 核心页面: 球员榜(分类榜单+进阶切换)、球队页(战绩+球员表+薪资)、球员页(基础数据+联盟排名+比赛日志)、赛程/比赛详情
- 「联盟第N」= 基于球员赛季数据的排名, 可用 SQL 窗口函数 rank() 算
